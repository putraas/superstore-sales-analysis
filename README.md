# Superstore Sales & Profitability End-to-End Data Analysis

Repositori ini berisi proyek analisis data komprehensif (*End-to-End Data Analysis*) menggunakan dataset transaksi ritel Global Superstore. Proyek ini dibuat sebagai bagian dari portofolio Data Analyst untuk mengevaluasi kinerja penjualan, profitabilitas kategori produk, efisiensi logistik, dan sebaran geografis pasar.

---

## 📊 Executive Summary & Key Metrics
* **Total Sales:** $2.30M
* **Total Profit:** $286.40K
* **Total Quantity Sold:** 38K Unit
* **Overall Profit Margin:** 12.47%

---

## 🛠️ Tools & Technologies Used
* **Python** (Pandas, Matplotlib, Seaborn) untuk data cleaning, eksplorasi, dan pemrosesan awal.
* **Microsoft Excel & Power BI** untuk pemodelan data interaktif dan pembuatan *Executive Dashboard*.

---

## 🔍 Key Insights & Business Findings
1. **Dominasi Produk (Sub-Category):** Sub-kategori *Phones* dan *Chairs* memimpin perolehan omset tertinggi (masing-masing mencapai ~$0.33M).
2. **Paradoks Kategori Furniture:** Meskipun kategori *Furniture* mencatatkan angka penjualan yang tinggi ($0.74M), kontribusi profit bersihnya sangat rendah ($0.02M) akibat tingginya tingkat diskon.
3. **Preferensi Pengiriman Logistik:** Sebagian besar pelanggan (~60.19%) memilih metode pengiriman **Standard Class**, menunjukkan bahwa efisiensi biaya pengiriman lebih diutamakan dibandingkan kecepatan kilat.
4. **Konsentrasi Pasar Geografis:** Aktivitas transaksi terpusat secara signifikan di kota-kota besar wilayah Pesisir Barat dan Timur Amerika Serikat (seperti California dan New York).
